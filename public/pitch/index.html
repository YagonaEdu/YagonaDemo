API Access

Ochiq REST API

Veb-kabinet va mobil ilovalar bitta REST API orqali ishlaydi. Markazlar o‘z saytlari, bot yoki hisob dasturlarini shu API bilan ulay oladi. API to‘liq OpenAPI sxemasi va Swagger hujjatiga ega.

  • POST/api/v1/auth/token — kirish, JWT
  • GET/api/v1/me/tenants — foydalanuvchi markazlari
  • GET/api/v1/students — o‘quvchilar
  • GET/api/v1/groups — guruhlar
  • GET/api/v1/lessons — dars jadvali
  • POST/api/v1/leads — saytdan yangi ariza
  • GET/api/v1/invoices — hisob-fakturalar
  • GET/api/docs/ — Swagger hujjati
# 1. Token olish
curl -X POST https://<server>/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"identifier":"admin@markaz.uz","password":"••••"}'

# 2. Markaz o‘quvchilari
curl https://<server>/api/v1/students \
  -H "Authorization: Bearer <access>" \
  -H "X-Tenant-ID: <markaz-uuid>"

# Javob (DRF sahifalash)
{
  "count": 53,
  "results": [
    { "full_name": "Yusupova Kamola",
      "status": "active", … }
  ]
}

Hozir API ishlab chiqish serverida ishlaydi; markazlar uchun ochiq kirish MVP bilan birga beriladi.
